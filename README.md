# astrbot_plugin_humanizer

AstrBot 出站润色插件：在回复发出前抹掉 AI 味话术壳，让文字更像真人在聊天窗口里随手打出来的。

## 做什么

- 删开场套话：这是一个很好的问题 / 作为一个人工智能 / 让我们一起来看看
- 删收尾套话：希望这对你有帮助 / 如果还有其他问题，欢迎随时提问
- 删废话连接词：总的来说 / 需要注意的是 / 首先，
- 书面词换口语：因此→所以、然而→不过、是否→是不是、倘若/若是→要是（单字「若」只在连词位置替换，成语不动）
- 清 IM 里的 markdown 痕迹：行首 `#` 标题、`**` 加粗、连续破折号、多余空行

代码块、行内代码、URL、平台组件标签（`<qqbot-at-user …/>` 这类）会先被切出来保护，
规则只作用于普通正文，所以代码示例里的「因此」、链接、@ 卡片不会被改到一个字节。

图文混排的消息链按 Plain 段原位改写（改动落在组件自己的 `text` 上），不会再走
`completion_text` 的二传手——那条 setter 会剔掉所有 Plain 再整段插到索引 0，图片顺序会被打乱。

## 安装

把整个目录放进 AstrBot 的 `data/plugins/` 下，重启 AstrBot（或热重载插件）。

## 配置

所有规则可在 WebUI 里单独开关：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enable` | true | 总开关 |
| `strip_openers` / `strip_closers` | true | 删开场 / 收尾套话 |
| `strip_connectives` | true | 删只起转场作用的连接词 |
| `colloquial_swap` | true | 书面词换口语词 |
| `clean_markdown` | true | 清 IM 里的 markdown 痕迹 |
| `custom_remove` | [] | 自定义要删的短语正则 |
| `llm_rewrite` | false | 可选：用模型再润色一遍 |
| `llm_provider_id` | "" | 润色档用的模型实例 ID，留空则跳过 |

`llm_rewrite` 开了以后，润色结果要过三道闸：空输出、把工具调用写成正文、长度失控，
任何一道不过都退回确定性规则的结果，不会把坏稿发出去。

## 说明

- 只挂在 `on_llm_response` 上，不改框架、不依赖其它插件。
- 规则把整条回复吃空时会保留原文，不会因为润色发出一条空消息。
